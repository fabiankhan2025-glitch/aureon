# AUREON (AUR)

AUREON is an experimental open-source cryptocurrency project.

## Project Goals
- Explore the design of a blockchain with its own native coin.
- Proposed coin name: AUREON
- Proposed symbol: AUR
- Proposed maximum supply: 21,000,000 AUR
- Begin with a local prototype and test network.
- Prioritize security, transparency, and responsible development.

## Current Status
This project is under development. No production blockchain or public coin launch is available yet.

## Roadmap
1. Document the blockchain protocol.
2. Build a local prototype.
3. Test transactions and supply rules.
4. Review security and legal requirements.
5. Consider a public network only after testing.

## Important Notice
AUR has no guaranteed market price or profit. Do not use this prototype for real-money transactions or investments.
